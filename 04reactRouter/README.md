## react-router-dom

> React Router DOM is the standard routing library for React web applications. It allows you to create single-page applications (SPAs) where navigation between pages happens without a full page reload.

<br>

| API             | Purpose                   |
| --------------- | ------------------------- |
| `BrowserRouter` | Enables routing           |
| `Routes`        | Holds route definitions   |
| `Route`         | Maps URL to component     |
| `Link`          | Navigation without reload |
| `NavLink`       | Active navigation links   |
| `useNavigate()` | Navigate programmatically |
| `useParams()`   | Read URL parameters       |
| `useLocation()` | Access current location   |
| `Outlet`        | Render nested routes      |
| `Navigate`      | Redirect users            |
